Help with setting up and using ScamGuard.

Set up Screen Scan (double-tap to check)

  • In ScamGuard, tap Add Screen Scan shortcut, then Add Shortcut.
  • Open Settings › Accessibility › Touch › Back Tap › Double Tap and choose Screen Scan. Got an Action Button? Settings › Action Button › Shortcut › Screen Scan.
  • The first time, Shortcuts asks to share with ScamGuard — tap Always Allow.

Double-tap doesn't do anything

  • Check Back Tap is set to Screen Scan (Settings › Accessibility › Touch › Back Tap).
  • Leave Triple Tap unassigned — it makes Double Tap slower to respond.
  • A thick case can make Back Tap less reliable. You can also run Screen Scan from the Shortcuts app.

Check a QR code

Open ScamGuard and tap Scan a QR code, then point the camera at the code. ScamGuard shows what the code does — for example "QR code opens paybyphone-au.com" — without opening it. The first time, allow camera access. You can also take a photo of the code and choose Check a screenshot, and Screen Scan checks QR codes in emails and messages too.

On a parking meter or sign, pay in the operator's official app if you can, and check the code isn't a sticker stuck over the real one.

Block calls from a scammer

Turn on ScamGuard in Settings › Apps › Phone › Call Blocking & Identification, then tap Block calls from this number on a check. Blocking stops calls only — for texts, use "Report Junk" in Messages.

Family mode

On a relative's phone, open ScamGuard › Settings › Family mode, choose yourself from Contacts, and turn it on. They'll see one simple screen, and an "Ask" button that drafts a text to you whenever something looks risky. Settings are behind a "Hold to open" button so they aren't changed by accident.

Think you've been scammed?

Contact your bank straight away, then report it to Scamwatch. For identity theft, IDCARE offers free support.
